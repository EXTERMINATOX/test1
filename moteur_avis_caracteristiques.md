# Spécifications du Moteur de Personas et Avis (Prop Canada V5)

## 1. Vue d'ensemble du système
Le générateur d'identités a été conçu pour remplacer une logique de sélection aléatoire simple par un véritable **Moteur de Profilage Psychologique**. Ce système génère des identités virtuelles (pseudonymes) pour la section des avis clients (`reviews-data.js`) et pour les notifications dynamiques ("Social Proof" dans `script.js`).

## 2. Base de données Lexicale Massive
Le moteur s'appuie sur une base de données interne colossale (plus d'un million de combinaisons possibles) pour garantir une unicité quasi totale :
- **Prénoms Anglophones** : 333 prénoms.
- **Prénoms Francophones** : 306 prénoms.
- **Noms de famille** : 206 noms.
- **Mots-clés Cryptos** : 54 termes (Anon, Ghost, BTC, Ledger, Gwei, etc.).
- **Mots-clés Professionnels** : 54 termes (Props, Director, VFX, ArtDir, etc.).
- **Mots-clés Street / Hustle** : 52 termes (Plug, Cartel, Trap, Drip, Sauce, Fire, etc.).
- **Mots-clés Gamers** : 51 termes (Sniper, NoScope, xX, TTV, Slayer, etc.).
- **Mots-clés Abstraits** : 72 termes (Neon, Mango, Bear, Dark, etc.).
- **Indicateurs Géographiques** : MTL, QC, VanCity, TO, 514, 416, etc.

## 3. Logique Démographique et Linguistique
Le système intègre un détecteur linguistique intelligent :
- **Analyse du contexte** : L'algorithme lit le texte de l'avis soumis.
- **Détection Francophone** : S'il détecte des mots comme "livraison", "merci", "parfait", "qualité", la probabilité bascule sur un profil francophone.
- **Cohérence Automatique** : Un profil francophone héritera de prénoms français et d'indicateurs locaux (ex: MTL_Plug, AcheteurVerifie, Mathieu Tremblay), tandis qu'un profil anglophone recevra des traits correspondants.

## 4. Les 7 Personas (Profils d'Acheteurs)
La génération est divisée en 7 "Personas" probabilistes qui dictent le comportement du formatage :

### Profil A : L'Acheteur Normal (35%)
Comportement classique d'e-commerce.
- *Formats* : `Prénom Nom`, `Prénom I.`, `Initiales`, `Prénom_Nom`, `Prénom + Année`.

### Profil B : Le Parano / Crypto (25%)
Acheteur soucieux de sa confidentialité.
- *Formats* : `Anon_X`, `Mot-Clé Crypto`, `[Redacted]`, `VerifiedBuyer`, `Chaînes Aléatoires courtes`.

### Profil C : Le Hustler / Street (15%)
Acteur du marché gris, fier de son statut.
- *Formats* : `Geo_Keyword`, `KeywordStar`, `Prénom_Keyword`.

### Profil D : Le Professionnel (10%)
Acheteur corporatif (Vidéoclips, Cinéma, Accessoiriste).
- *Formats* : `Keyword_Geo`, `IndieKeyword`, `Nom_Keyword`.

### Profil E : Le Gamer (7%)
Acheteur adoptant des codes du jeu vidéo.
- *Formats* : `xX_Sniper_Xx`, `TTV_Kaleb`, `Slayer991`.

### Profil F : L'Abstrait / Aléatoire (6%)
Noms de type "Reddit" ou "Discord", combinant des mots au hasard.
- *Formats* : `NeonMango`, `DarkBear99`.

### Profil G : Le Compte Jetable "Burner" (2%)
Acheteur pressé tapant n'importe quoi sur le clavier.
- *Formats* : `user_1234`, `asdfg`, `test_compte`.

## 5. L'Illusion Indétectable (Imperfections & Micro-Avis)
- **Oubli des majuscules (15%)** : Le pseudo complet se retrouve en minuscules.
- **Caps Lock coincé (2%)** : Le pseudo est hurlé en majuscules.
- **Emojis discrets (2%)** : Ajout naturel d'un symbole pertinent.
- **Avis ultra-courts et emotes** : Injection de centaines de commentaires d'un seul mot ou emote (`🔥🔥🔥`, `...`, `ok`, `No cap`) pour casser le rythme visuel et le rendre parfaitement organique.
